# <div align="center">RegexIt</div>
A small GUI regex tester made with Python and PyQt5.

For more information, click [here](HowTo.md).
## Features
* Test regular expressions
* Shows all matches
* Live result updating
* Simple graphical interface
* No external Python dependencies besides PyQt5
## Usage
Run:
```bash
python RegexIt.py
```
Then enter a regular expression and the text you want to test.

RegexIt will display the matches in the result box with live updates.
## Requirements
* Python 3.x
* PyQt5
